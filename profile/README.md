<h1 align="center">URMA</h1>
<p align="center"><strong>Your work deserves to outlive its host.</strong></p>
<p align="center">For the right to report. For code that stays within reach.</p>

Platforms can disappear. Accounts can be suspended. Devices can be lost.
Your code and evidence need a way back.

**URMA puts the data itself on-chain, not just a link to someone else's server.**
Publish and recover without depending on GitHub or a conventional centralized hosting server.
Independent readers verify the bytes, and recovery no longer needs the original publisher's service.

### Undeletable Git snapshots

**Take down the repository. The snapshot has another home.**

URMA Git turns committed code into recoverable on-chain snapshots, with verified checkout.
Deleting a GitHub page cannot remotely erase copies retained by independent nodes.
Keep the history. Recover the code. Build beyond a single host.

### Journalism and freedom of the press

**A lost device should not take the story with it.**

URMA Capture gives journalistic originals and their context an encrypted recovery route beyond the device that captured them.
Published private records can be recovered with the owner's recovery secret, without the original application or publisher service.

### One protocol. More ways to keep your work within reach.

- **Archive:** encrypted files, directories and collections.
- **Wire:** public text, identities, replies and a locally verified feed.
- **Web + Names:** publish site packages and resolve them through on-chain names.

### Build with URMA

An open protocol, a working command line and reusable Rust libraries.
Use the tools directly or build your own application on the same records, proofs and recovery rules.
