<h1 align="center">URMA</h1>
<p align="center"><strong>For the right to report. For code that stays within reach.</strong></p>

URMA is an open protocol for publishing data on-chain and recovering it without depending on GitHub or a conventional centralized hosting server.
The data itself is preserved in the distributed ledger, not just a link to a file on someone else's server.

### Undeletable Git snapshots

A repository takedown should not be the end of its history.
URMA Git publishes committed snapshots and recovers them with verified checkout.
A centralized host cannot remotely erase copies already retained by independent nodes.
Recovery needs accessible records, not permission from the original hosting provider.

### Journalism and freedom of the press

URMA Capture preserves journalistic originals and their context through encrypted publication and recovery.
Private files stay encrypted and are recovered with the owner's recovery secret.

The same protocol also supports encrypted archives, public text and identities through Wire, and Web packages with Names-based resolution.

### Build with URMA

The [Rust workspace and CLI](https://github.com/urma-protocol/urma) provide reusable libraries for records, proofs, identities, publication and recovery.
Start with the [command-line guide](https://github.com/urma-protocol/urma/tree/master/urma-cli#readme), explore the [published Rust packages](https://crates.io/search?q=urma), or browse the source.
